# Fetch Modern UI Styles

Use the 21st.dev MCP server to get modern, production-ready component styles.

1. **Identify the component** that needs styling (button, card, input, navbar, etc.)

2. **Use 21st MCP** to search for and fetch modern component implementations:
   - Search for the component type
   - Review available styles and variants
   - Pick the most modern, visually impressive option

3. **Adapt the style** to the project's design system:
   - Use the project's color variables (indigo/purple palette)
   - Maintain dark theme consistency
   - Ensure it works with HeroUI and Tailwind CSS v4
   - Apply glass morphism and gradient effects where appropriate

4. **Integrate** the styled component into the codebase
